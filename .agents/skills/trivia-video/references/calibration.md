# The question bar

Read this before CALIBRATE picks anything. This is the product's quality bar — not render quality.
A beautiful video built on a bad set fails. An ugly video built on a good set works.

## The band

A set is calibrated when a viewer **gets some right and some wrong in the same set.**

- Too easy is boring. Nothing to feel smart about.
- Too hard is ridiculous and kills the format outright.
- The feeling you are aiming at is the excitement of knowing the answer — which requires that
  knowing it was not guaranteed.

**The one strategy available:** niche areas people believe they are smart about *because* they know
that area. A question inside someone's self-identified domain is the one they are thrilled to get
right, and it is the only known way a set is hard and satisfying at once rather than hard and
alienating. This is a heuristic and it has not been tested. It is also the only guidance that
exists for the hardest part of the product, so use it and watch what happens.

## The shape of the step

Not "produce ten questions." **Candidate, then select.** SOURCE generates a wide pool without
judging; CALIBRATE applies the band and picks the set that ships. Judge against the band, never
against whether a question is interesting — interesting and calibrated are different axes and only
one of them is the bar.

## Three things CALIBRATE owes beyond picking

1. **Confirm every answer is actually right.** SOURCE ran on the cheap model on purpose, and a
   wrong answer in a trivia video is a product failure, not a cosmetic one. Check each one against
   a source. If one cannot be confirmed, drop it and pick another — do not ship a maybe.
2. **Check nothing repeats.** Recall from the `TikTokTrivia` bank before picking, and retain the
   set you pick — `hindsight memory recall TikTokTrivia "questions already used"`, then
   `hindsight memory retain TikTokTrivia "<the questions this run shipped>"`. This step runs
   weekly; without it the same questions resurface inside a month.
3. **Name your doubt.** One question, the one closest to the edge, and which edge. This is
   mandatory and it is the most useful sentence in the whole session.

## The test

Play a finished set with the pause-and-guess ritual.

- **Pass** — some right, some wrong, in the same set.
- **Fail** — all right (too easy), or all wrong (ridiculous, no fun).

## What the cut owes the questions

The format works because the viewer pauses and guesses before the answer lands. Two consequences
that belong to ASSEMBLE but are decided here:

1. **Leave the gap.** Videos in this trend are too fast to play along with. That is a defect in the
   source material and one these can fix rather than inherit.
2. **Captions have to be readable** at the speed the gap allows, because reading is how a viewer
   holds the question during the pause.

## Working size

Ten questions, roughly two minutes read aloud with gaps. Treated as the contract; it came in as an
example figure, so if a set wants to be eight or twelve, that is Carrie's call and not a violation.
